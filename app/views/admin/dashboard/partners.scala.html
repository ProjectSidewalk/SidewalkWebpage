Partners #

These logos render in the "Community Partners" section of the landing page: the global list on every Project Sidewalk deployment, and the city list only on this city's page (global logos come first). Logos are re-encoded server-side — upload the highest-quality PNG (transparency preserved) or JPEG you have, ideally a wide wordmark on a transparent background. An SVG works too: this page renders it to a PNG before uploading, so its type has to be outlines rather than live text. The name is shown to visitors as a tooltip when they hover the logo, and doubles as the link's log label; the URL is where a click goes; alt text is what screen readers announce (defaults to "name logo").

Official contact notice #

Optional. When set, this city's landing page shows a sentence under the partner logos, so residents don't expect a response to what they map here. It's off until you add a URL; clearing the URL turns it off again. The sentence is translated for every language, but the name is shown exactly as you type it, so write it the way it reads mid-sentence.
