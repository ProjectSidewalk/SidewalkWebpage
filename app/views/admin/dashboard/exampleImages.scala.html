Example Images #

Authoring for the example imagery under public/images/examples/ — the photos that teach a tag, a severity level, or a Validate “why not?” reason. Capture a fresh photo from any label, mark up what it depicts, then export the image and annotations.json and commit them both. Nothing here writes to disk: they are source, so they go through git like any other source.

Coordinates are stored as fractions of width and height, so one record renders correctly at every size the image appears at, from a 125 px Explore tooltip to the full-resolution file.

Source #

Browse in Gallery or the Label Map, then paste the ID here. The panorama opens at the point of view the label was placed from; reframe it however the example should look, then capture.

Marks #

Press on the feature, drag out to clear space, release. The first press is the precise one. Drag an existing mark to move it.

Manifest #

The whole of public/images/examples/annotations.json, live. Paste over the file and commit; make lint-example-images validates it.
