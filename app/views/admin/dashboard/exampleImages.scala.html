Example Images #

Annotation authoring for the example imagery under public/images/examples/. Pick an image, place marks over the feature it is meant to teach, then copy out annotations.json and commit it. Nothing here writes to disk — annotations are source, so they go through git like any other source.

Coordinates are stored as fractions of width and height, so one record renders correctly at every size the image appears at, from a 125 px Explore tooltip to the full-resolution file.

Press on the feature, drag out to clear space, release. A type marker is a single click.

Manifest #

The whole of public/images/examples/annotations.json, live. Paste over the file and commit; make lint-example-images validates it.
