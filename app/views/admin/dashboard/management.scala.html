Management #

Set contributors' roles and teams, manage teams, and run maintenance jobs. Every change here applies to live data immediately.

Loading…

Users #

Every contributing account. Owner accounts can't be reassigned. Click a name for that user's admin profile, which holds manual quality, infra3D access, and marking work by date.

Teams #

Status sets whether a team accepts new members; visibility sets whether it appears in public team lists. Click a team's name for its members and their contributions.

Maintenance #

These jobs can be slow and change what every user sees; each asks for confirmation first.

Recalculate user stats Recomputes each contributor's labeling rate and high-quality flag.
Recalculate street priority Recomputes every street's audit priority so under-audited streets resurface.
Recalculate validation counts Recounts every label's agree, disagree, and unsure votes, skipping excluded users. Afterward, run "Recalculate user stats" and "Recalculate street priority".
Generate crops Cuts missing label crops from the self-hosted pano store. Runs nightly.
Rebuild sidewalk presence Re-derives each street side's sidewalk verdict from current labels. Runs nightly.
Refresh places Fetches the city's destinations (schools, clinics, transit stops, parks, and more) from OpenStreetMap for the AccessScore map. Runs weekly.
Recount street gradient staleness Counts streets with no grade and streets whose geometry changed since sampling, for the Health page. Runs nightly; run it now after importing grades (sampled offline; see the street gradient docs).
Clear server cache Clears Play's cache; the next page loads rebuild it.
